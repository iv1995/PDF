You can call the API by using this URL : localhost:8081/process/PDF20.pdf

It is advisable to use the PDF20.pdf since it is one of the tagged PDF files I have found so far and 
some of the features (concerning tagged PDFs) have been adjusted for this specific pdf file 
because they used the H1 tag instead of the CAPTION tag for image captions.

Once the PDF file has been processed the results should be available in the Storage/Output directory.
If you want to use a new PDF file you wil have to copy it inside the Storage/Input/PDF directory.

Make sure to check and (if necessary) delete the old results that may be available inside the Storage/Output folders 
(do not delete any folder inside the Storage/Output folder).
