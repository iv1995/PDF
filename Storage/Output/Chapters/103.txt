7.7.3.4Inheritance of page attributes 
 
Some of the page attributes shown in "Table 31: Entries in a page object" are designated as inheritable. 
If such an attribute is omitted from a page object, its value shall be inherited from an ancestor node in 
the page tree. If the attribute is a required one, a value shall be supplied in an ancestor node. If the 
attribute is optional and no inherited value is specified, the default value shall be used.
