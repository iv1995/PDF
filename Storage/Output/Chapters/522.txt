As shown on the left, the basic markup for a radial dimension consists of an arrow pointing to a circle or 
arc that is connected to a leader line and text label that defines the radius or diameter. If the arrow is 
positioned such that it is off the underlying arc, as in the figure on the right, an extension arc is 
generated that clarifies which arc is being measured. 
For radius measurements, the measure value is preceded by an "R" in the measure string. For diameter 
values, the measure value is preceded by the diameter symbol (⌀).
