 
 
Standard structure elements in the default (PDF 1.7) namespace 
(Normative) 
This Annex identifies the set of structure elements that are in the standard structure namespace for PDF 
2.0 (see 14.8.6, "Standard structure namespaces"). The default standard structure namespace includes 
the set of structure elements defined in ISO 32000-1, 14.8 "Tagged PDF", which are therefore subject to 
the rules of tagged PDF as specified in ISO 32000-1, 14.8 "Tagged PDF".
