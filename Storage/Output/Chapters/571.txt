#Table 377: Standard layout attributes" summarizes the standard layout attributes and the structure 
elements to which they apply. 
As described in 14.8.5.3, "Attribute Values and Inheritance" an inheritable attribute may be specified for 
any element to propagate it to descendants, regardless of whether it is meaningful for that element.
