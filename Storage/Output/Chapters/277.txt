A metadata stream representing document-level metadata can be attached to a PDF document through

Metadata
A metadata stream representing object-level metadata can be attached to the object through the 
 entry in a stream or dictionary representing the object or associated with the object (see 
"Table 348: Additional entry for components having metadata"). 
Object level metadata can also be associated with marked content within a content stream, by including 
a metadata stream in the property list dictionary for this marked content. Because a stream dictionary 
is always an indirect object, a property list containing a metadata stream cannot be encoded inline in 
the content stream, but needs to be encoded as a named resource (see 14.6.2, "Property lists").
